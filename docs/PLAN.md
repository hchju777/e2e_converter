# SAV 지표 계산 로직 구현 계획

## 배경

- `db/UCB_20260518_180044 - (dummy).xlsx`의 **Summary 시트**가 지표 계산 스펙 테이블.
  - 컬럼: `구분`, `항목`, `문항`, `SAV 변수`, `계산`, `배너조건`, 그리고 분기별 결과 컬럼(`25년 1차` ~ `26년 12차`, 총 24개).
  - 전체 1,974행 = 지표 329개 × 배너조건 6종(`전체`, `Area=1`, `Area=2,3,4,5,6`, `UCB_Tier=1`, `UCB_Tier=2`, `UCB_Tier=3,99`).
  - `25년 1차` ~ `26년 5차`까지는 값이 이미 채워져 있고, **`26년 6차`부터는 전부 비어있음**.
- `db/(0709)피부과(6차)_v2.0.SAV`는 Period=6, 응답자 35명 — Summary 시트의 빈 칸인 **`26년 6차`**를 채우기 위한 원본 데이터로 추정됨.
- 이번 범위: `배너조건 == '전체'`인 329행만 계산 (다른 배너조건은 이후 확장).

## Summary 시트 분석 결과 (배너조건=전체, 329행)

| 계산 타입 | 행 수 | 설명 |
|---|---|---|
| `SUM` / `Sum` | 243 | SAV 표현식을 응답자별로 계산 후 합산 |
| `계산식` | 69 | 다른 행의 결과를 참조하거나, 괄호 없는 산술식을 직접 계산 |
| `Mean` | 12 | 응답자별 계산값의 평균 |
| `Count` | 1 | `PID` — 유효 응답자 수 (=35) |

- `SAV 변수` 표현식 패턴
  - 단일 변수: `PID`, `SQ4`, `Q1` 등 (195행)
  - 사칙연산 조합: `SQ5_1 + SQ5_2`, `Q3_1-(Q6_A_11 + Q6_B_11 + Q6_C_11_n2)-(Q6_A_16 + Q6_B_16 + Q6_C_16_n2)` 등 (65행)
  - 괄호 참조식: `[Q3_1-(...) Mean] / [SQ5_1 + SQ5_2 Mean] *100` 형태로, 다른 행의 이미 계산된 값(SAV변수+계산타입으로 매칭)을 가져와 조합 (69행)
- `~`(범위), `,`(리스트) 표기나 Q15 만족도 문항은 이번 범위(Summary/전체)에는 없음 — "분기 문항" 시트 전용이라 제외.

## 구현 단계

1. **스펙 로더** (`load_spec()`)
   - Summary 시트를 읽어 `배너조건 == '전체'`인 329개 행을 `{구분, 항목, 문항, sav_expr, calc_type, banner}` 레코드로 파싱.

2. **SAV 로더**
   - 기존 `read_sav.py`의 `read_sav_files()` 재사용.

3. **수식 평가 엔진**
   - `ast` 모듈 기반으로 SAV 변수 산술식을 안전하게 파싱/계산 (`eval` 미사용, 임의 코드 실행 방지).
   - `Count`: 유효 응답자 수 카운트.
   - `Sum` / `SUM`: 응답자별 계산값의 합.
   - `Mean`: 응답자별 계산값의 평균.
   - `계산식`:
     - `[식 AGG]` 참조 → 동일 배너 내에서 `SAV 변수`(trim) + `계산` 타입이 일치하는 다른 행의 기 계산값을 찾아 대입 후 최종 산술식 평가.
     - 괄호 없는 순수 산술식(예: `Q1/(SQ5_1+SQ5_2)*100`) → 각 항을 SUM으로 집계한 뒤 계산 (Sum/Sum = Mean/Mean이므로 결과 동일함을 기존 데이터로 확인).

4. **실행**
   - 329개 행 전체 계산 → 결과를 `results.csv`(또는 xlsx)로 저장.
     - 컬럼: `구분`, `항목`, `문항`, `SAV 변수`, `계산`, `배너조건`, `26년 6차_계산값`
   - 원본 xlsx는 수정하지 않음 (출력 방식으로 확정).

5. **검증**
   - 기존에 채워진 `26년 5차` 등 인접 분기 값과 스케일을 비교해 계산 로직 오류를 조기에 발견 (sanity check).
